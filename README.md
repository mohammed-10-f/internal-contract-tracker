# نظام متابعة العقود — V14.1

نظام متابعة معاملات العقود مبني على Cloudflare Workers وD1، بواجهة عربية RTL ومسار عمل واضح بين HR ومسؤولي الأقاليم.

## أبرز التحسينات

- واجهة أخف وأسرع.
- شاشة رفع موحدة للفردي والجماعي.
- صلاحيات قابلة للتعديل من شاشة المستخدمين.
- تفويض مركزي ينقل المعاملات النشطة ويطبق على المعاملات المستقبلية.
- إسناد المعاملة من داخل تفاصيلها فقط.
- اعتماد سريع من قائمة المعاملات.
- لوحة قيادة لمسؤولي الأقاليم لآخر 7 أيام.
- تحليلات أداء قابلة للتصفية والتصدير.
- سجل نشاط جدولي قابل للتصدير.
- إدارة أقاليم مع تفعيل وتعطيل.
- Timeline أفقي داخل تفاصيل المعاملة.
- D1 indexes + batch queries + short-lived caching لتقليل زمن الاستجابة.
