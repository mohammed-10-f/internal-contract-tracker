# نظام متابعة العقود — V20.0.0

منصة داخلية لإدارة دورة المعاملة، الإسناد المباشر للمسؤول، الزمن، التقارير، والتفويض.

## النموذج التشغيلي الجديد

أصبحت العلاقة الأساسية:

`المعاملة → المستخدم المسؤول`

ولا يوجد كيان «إقليم» في واجهة النظام أو منطق العمل أو نموذج الرفع.

## أهم التغييرات

- حذف شاشة الأقاليم نهائياً.
- حذف إضافة/أرشفة/إعادة تفعيل الأقاليم.
- ربط المعاملة مباشرة بالمستخدم المسؤول.
- حسابات المسؤولين تدار من شاشة المستخدمين عبر الدور «مسؤول».
- عند تعطيل مسؤول، يمكن إعادة تفعيل حسابه من شاشة المستخدمين؛ المعاملات التاريخية تبقى مرتبطة بمعرفه.
- الرفع الفردي يتطلب اختيار المسؤول مباشرة.
- الرفع الجماعي من Excel يتطلب عمود «المسؤول» ويمكن استخدام اسم المسؤول أو اسم المستخدم.
- إعادة تصميم تحليل الأداء إلى خمسة مؤشرات فقط:
  1. إجمالي المعاملات
  2. تم التوثيق
  3. منسحب الموظف
  4. المعاملات المتأخرة
  5. أُغلقت بعد التأخير
- مقارنة المستخدمين تستخدم نفس فترة التاريخ المختارة لضمان عدالة المقارنة.

## ترقية قاعدة البيانات

عند أول طلب بعد نشر V20، يقوم Worker بترحيل قاعدة D1 القديمة تلقائياً:

1. تحويل دور `region` القديم إلى `responsible`.
2. نقل `region_user_id` إلى `responsible_user_id`.
3. تحويل حالات سير العمل القديمة إلى حالات المسؤول الجديدة.
4. تحويل مراحل السجل من `region` إلى `responsible`.
5. إعادة بناء جداول المستخدمين والمعاملات لإزالة الأعمدة الإقليمية من المخطط الحي.
6. حذف جدول الأقاليم القديم.
7. تحديث `schema_meta` إلى 23.

## فحص الصحة

`/api/health` يعرض إصدار المخطط وعدد حسابات المسؤولين وأعمدة جدول المعاملات الحالية.

## النشر

- Root directory: مجلد المشروع.
- Build: يمكن استخدام `bun install` فقط إذا كانت بيئة البناء تسمح بتثبيت الاعتماديات.
- لا يعتمد المشروع على تنزيل Wrangler أثناء التثبيت.
- إعدادات D1 وAssets موجودة في `wrangler.toml`.
