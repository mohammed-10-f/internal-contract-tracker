# Contract Control — 1S.1

نسخة 1S.1 النهائية لإدارة دورة المعاملات.

## أهم التغييرات
- فصل صلاحية الاطلاع عن صلاحيات الإجراءات.
- المشرف يستطيع استعراض المعاملات النشطة والموقوفة والمنتهية والمرفوضة دون تنفيذ إجراءات عليها.
- استبدال فلترة الأقاليم في قائمة المعاملات بفلترة المسؤول.
- تبسيط إفادة الانسحاب إلى نموذج واحد واضح.
- رقم معاملة الانقطاع / اتخاذ الإجراء جزء من ملخص المعاملة.
- إعادة تصميم بطاقة المعاملة وتفاصيلها وسجل الحركة الجانبي.
- تحسين عرض الجوال والحقول والتواريخ.
- إصلاح نموذج Excel: قائمة الأقاليم في عمود الإقليم فقط، والتاريخ في عموده الصحيح.
- إزالة النصوص الإرشادية والعبارات المكررة من تفاصيل المعاملة.
- الحفاظ على إعدادات Cloudflare D1 وملفات النشر.
